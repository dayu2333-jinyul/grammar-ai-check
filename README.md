# Grammar AI Check

Free AI-powered grammar and spelling check. Free online tool — no registration required.

## 🌐 Website

**[grammaraicheck.com](https://grammaraicheck.com)**

## 📋 Features

- Free AI-powered grammar and spelling check
- Style and clarity suggestions
- Text history (localStorage, up to 10 entries)
- 24 in-depth English writing guides

## 📂 About This Repository

This repository hosts the open-source landing page and documentation for [grammaraicheck.com](https://grammaraicheck.com). The actual web application is deployed on Cloudflare Pages.
